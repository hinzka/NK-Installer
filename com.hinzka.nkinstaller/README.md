# NK Installer

VRChat向けアバター用のフェイストラッキングセットアップを導入するための Unity Editor ツールです。

VCC / VPM からインストールして使用できます。

## Installation

VCC（VRChat Creator Companion）にVPMリポジトリを追加し、対象のUnityプロジェクトへ **NK Installer** をインストールしてください。

## Requirements

- VRChat SDK - Avatars
- Unity / VRChat Creator Companion
